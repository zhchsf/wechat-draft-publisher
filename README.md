# 微信公众号草稿发布器

这是一个 macOS 优先的 Electron 本地应用。它读取本地 HTML 文章，解析文章目录内的图片资源，将正文图片和封面上传到微信公众号，再把文章创建到公众号草稿箱。

## 当前功能

- 选择多个 HTML 文件或目录，目录会递归发现 `.html` 和 `.htm` 文件。
- 每个 HTML 对应一个独立草稿，可批量顺序发布。
- 从 HTML 元信息预填标题、作者、摘要、原文链接和封面。
- 只处理目录内的 PNG、JPG、JPEG、GIF、WEBP 本地图片，并对重复图片去重。
- 展示安全沙箱预览、资源问题清单和逐项忽略选项。
- 保存导入队列、公众号配置和发布历史，失败文章支持重试。
- 仅调用微信草稿接口，不会直接发布或群发文章。

## 开发运行

需要 Node.js 20 或更高版本。当前项目的 Node 14 仅适合读取工程文件，不适合构建新版 Electron 应用。

```bash
npm install
npm test
npm start
```

## 打包

```bash
npm run dist
```

安装包输出到 `dist/`。首版没有 Apple Developer 签名和公证配置，macOS 首次启动时需要在 Finder 中确认打开。

## 微信配置

在“公众号设置”中填写一个公众号的 AppID 和 AppSecret。运行电脑的公网出口 IP 必须加入微信公众号后台的 IP 白名单。配置保存在 Electron 用户数据目录的 `state.json`，文件权限为 `0600`；不要把它复制或提交到公共位置。

## HTML 约定

文章可以是任意 `.html` 或 `.htm` 文件。相对路径图片应位于 HTML 所在目录或其子目录中，例如：

```text
article-folder/
  article.html
  images/
    cover.jpg
    body-01.png
```

首张有效本地图片默认作为封面。正文中的脚本、外部样式依赖、远程图片和不支持的资源会被列为问题；确认忽略后，相关资源会从提交内容移除。
